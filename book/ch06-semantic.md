# Իմաստային վերլուծություն

Շարահյուսական վերլուծության արդյունքում կեռաս ծրագրից կառուցվում 
է վերացական շարահյուսական ծառ, որը, բնականաբար, արտացոլում է 
տրված ծրագրի միայն շարահյուսությունը։ Ինչպես բնական լեզուներում 
կարող է նախադասությունը շարահյուսորեն ճիշտ լինել, բայց պարունակել
իմաստային սխալներ, այնպես էլ ծրագրավորման լեզուների ծրագրերը
կարող են ճիշտ շարահյուսությամբ կազմված լինել, բայց իմաստային
սխալների պատճառով անհնար լինի դրանց թարգմանությունը կամ կատարումը։
Օրինակ, Կեռաս լեզվով գրված է ծրագիր․

```basic
SUB f(r AS REAL, t AS TEXT)
    DIM b AS BOOL
    LET b = r * t
END SUB
```

Սա շարահյուսորեն ճիշտ ծրագիր է։ Իսկապես, ենթածրագիրը ճիշտ է 
սահմանված․ `DIM`-ով սահմանված է `b` տրամաբանական տիպի 
փոփոխականը, `LET`-ով `b` փոփոխականին վերագրվում է `r * t`
արտահայտությունը։ Բայց, ակնհայտ է, որ այնտեղ երկու իմաստային
սխալ կա։ Առաջինը՝ `r`-ը, որ իրական թիվ է, չի կարելի 
բազմապատկել `t` տեքստով։ Երկրորդը՝ `b` տրամաբանական 
փոփոխականին հնարավոր չէ վերագրել իրական արժեք, քանի որ
`*` գործողության արդյունքը միշտ իրական թիվ է։

Այսպիսով, բնական անհրաժեշտություն է առաջանում շարահյուսական
վերլուծությունից հետո ծրագիրը, ավելի ճիշտ՝ ծրագրից կառուցված
վարացական շարահյուսական ծառը, ենթարկել իմաստային (կամ
իմաստաբանական) վերլուծության։ Այս գլխում կցուցադրեմ Կեռաս
լեզվի իմաստային վերլուծության իրականացումը։

Կեռասի իմաստային վերլուծիչն աշխատում է երկու անցումով։ 
Առաջինով, որ կոչվում է `NameResolutionPass`, որոշվում են բոլոր
անունների դերերը։ Վերը բերված օրինակում `f`-ը ենթածրագիր է,
`r`-ը և `t`-ն պարամետրեր են, `b`-ն լոկալ փոփոխական է։ Երկրորդով,
որ կոչվում է `TypeCheckingPass`, որոշվում են ու ստուգվում
են անունների ու գործողությունների տիպերի համապատասխանությունը։
Օրինակ, այս անցման ժամանակ ստուգվում է, որ բազմապատկման 
գործողության երկու օպերանդներն էլ պետք է իրական արժեքներ լինեն։
Նույն կերպ ստուգվում է, որ `LET` հրամանում վերագրվողն ու 
վերագրելին նույն տիպն ունեն։

Եթե իմաստային վերլուծության արդյունքում սխալներ չեն բացահայտվում,
ուրեմն վստահորեն կարելի է նպատակային կոդ գեներացնել։


## Սիմվոլներ

Անունների դերերը որոշելու և ճշգրտելու համար սահմանված է `Symbol`
նկարագրիչը, որը ներառում է այն բոլոր անհրաժեշտ տեղեկությունը, որը 
կոմպիլյատորին պետք է տվյալ անունը լիարժեք ներակայացնելու և հետագա
օգտագործման համար։

```c++
struct Symbol {
    SymbolId id{UnknownSymbol};
    SymbolKind kind{SymbolKind::Variable};
    std::string name;
    const Type* type{};
    VariableStorage storage{VariableStorage::Local};
    std::optional<SubroutineSignature> subroutine;
};
```
