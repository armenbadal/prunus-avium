# Կեռաս լեզվի նկարագրությունը

_Կեռասը_ Բեյսիկ լեզվից ածանցված լեզու է, որը պարզեցված ու հարմարեցված է 
որպես «Ծրագրավորման լեզվի նախագծում և իրականացում» թեմայով զրույցների 
գործնական աշխատանք։ Այն ներառում է ծրագրեր գրելու համար անհրաժեշտ 
նվազագույն միջոցներ՝ տիպեր ու ղեկավարող կառուցվածքներ։ Կեռասը, որպես
ուսումնական նախագիծ, ի սկզբանե նախատեսված է ընդլայնվելու համար։ Մեր
զրույցների ընթացքում կիրականացնենք դրա բազային տարբերակը, բայց նաև
կսահմանենք ընդլայնման պրոյեկտներ, որոնցից ամեն մեկը մի նոր հնարավորություն
կավելացնի լեզվին։

Այսպիսով, Կեռասը ծրագիրը բաղկացած է ենթածրագրերից, որոնք կարող են 
կատարել և ֆունկցիայի, և պրոցեդուրայի դեր։ Բեկուսի-Նաուրի ընդլայնված
նոթագրությամբ կարող ենք ասել, որ.

```ebnf
Program = { Subroutine NewLines }.
```

Ենթածրագրի սահմանումն ավելի հետաքրքիր է։ 

```ebnf
Subroutine = 'SUB' IDENT [ '(' ParameterList ')' ] ['AS' TypeName] Sequence 'END' 'SUB'.
```

Պարամետրերի ցուցակում ստորակետով իրարից անջատված տիպիզացված 
պարամետրերն են.

```
ParameterList = Parameter { ',' Parameter }.
Parameter = IDENT [ '[' ']' ] 'AS' TypeName.
```

Եթե պարամետրի անունի կողքին գրված է `[]`, ապա դա զանգված է։

Կեռաս լեզվի պարզ տիպերը երեքն են. տրամաբանական, իրական-թվային ու 
տեքստային.

```ebnf
TypeName = 'BOOL' | 'REAL' | 'TEXT'.
```

Սահմանումից նկատում ենք, որ ենթածրագրի թե պարամետրերի ցուցակը, և թե 
վերադարձվող արժեքի տիպը պարտադիր չեն։ Օրինակ, կարելի է գրել պարամետրեր 
չունեցող ֆունկցիա.

```basic
SUB RandomNumber AS REAL
  ' հաշվել մի պատահական թիվ
END SUB
```

Կամ կարելի է սահմանել պրոցեդուրա.

```basic
SUB PrintDate
  ' տպել այսօրվա ամսաթիվը
END SUB
```

Ֆունկցիա-ենթածրագրից արժեք վերադարձնելու համար հատուկ հրաման կամ
գործողություն նախատեսված չէ (ինչպես շատ լեզուների `return`-ը)։ Վերադարձվող
արժեքը պարզապես վերագրում ենք ենթածրագրի անունին։ Օրինակ, երկու թիվ 
գումարող ֆունկցիան կսահմանվի.

```basic
SUB Add(x AS REAL, y AS REAL) AS REAL
  LET Add = x + y
END SUB
```

Նկատենք նաև, որ ենթածրագրից կարելի է վերադարձնել միայն պարզ արժեքներ։

Ենթածրագրի մարմնում օգտագործեցինք `Sequence`, որը պարզապես նշանակում
է իրար հաջորդող հրամաններ։ Ահա կանոնը.

```ebnf
Sequence = NewLines { Statement NewLines }.
```

Այսինքն՝ հրամանների ցուցակը պետք է անպայման սկսվի մեկ կամ ավելի նոր
տողին անցման նիշերով, և ամեն մի հրամաննից հետո էլ պետք է լինի գոնե
մեկ նոր տողին անցման նիշ։ Որտեղ.

```ebnf
NewLines = NEWLINE { NEWLINE }.
```

Հրամանները վեցն են. 

```ebnf
Statement = Dim | Let | If | While | For | Call.
```

Դրանք են՝ փոփոխական կամ զանգված սահմանող `DIM`-ը, վերագրման 
`LET`-ը, ճյուղավորման `IF`-ը՝ իր `ELSEIF` և `ELSE` ճյուղերով, նախապայմանով
ցիկլի `WHILE`-ը, և պարամետրով ցիկլի `FOR`-ը։

Փոփոխականներն ու զանգվածները սահմանվում են `DIM` հրամանով։ 

```ebnf
Dim = 'DIM' IDENT [ '[' Expression ']' ] 'AS' TypeName.
```

Եթե պարզ փոփոխական է սահմանվում, ապա տրվում է միայն անունն ու 
տիպը։ Իսկ զանգվածի համար (միաչափ) տրվում է նաև չափը. վերջինս
կարող է լինել ինչպես հաստատուն, այնպես էլ կատարման ժամանակ 
հաշվարկվող թվային արտահայտություն։

Վերագրման հրամանը փոփոխականին կամ զանգվածի տարրին նոր արժեք 
է վերագրում։ 

```ebnf
Let = 'LET' IDENT [ '[' Expression ']' ] '=' Expression.
```

Նկատենք, որ `LET` բառն այստեղ կոսմետիկ դեր է կատարում։ Լեզվի 
զարգացման վարժություններում կառաջարկենք այն դարձնել ոչ պարտադիր։

Ճյուղավորման հրամանը.

```ebnf
If = 'IF' Expression 'THEN' Sequence 
     { 'ELSEIF' Expression 'THEN' Sequence }
     [ 'ELSE' Sequence ]
     'END' 'IF'.
```

Այստեղ սահմանված է, որ `ELSEIF` բլոկները կարող են հանդիպել զրո
կամ ավելի անգամներ, իսկ `ELSE` բլոկը պարտադիր չէ։

Բոլոր `IF` և `ELSEIF` ճյուղերի պայմաններում արտահայտությունը
պետք է հաշվարկվի տրամաբանական արժեքի։ 

Նախապայմանով ցիկլն իր մարմնի հրամանները կատարում է այնքան 
ժամանակ, քանի դեռ `WHILE` բառից հետո գրված տրամաբանականը
արտահայտությունը հաշվարկվում է _ճշմարիտ_ (`TRUE`) արժեքի։

```ebnf
While = 'WHILE' Expression Sequence 'END' 'WHILE'.
```

Հաշվիչով կամ պարամետրով ցիկլի `FOR` հրամանն իր մարմինը կատարում
է այնքան ժամանակ, քանի դեռ տրված սկզբնական արժեքով պարամետրը
չի ստացել տրված վերջնական արժեքը։ Լռելությամբ պարամետրը փոխվում 
է մեկով, բայց կարելի է սահմանել նաև փոփոխման քայլը.

```ebnf
For = 'FOR' IDENT '=' Expression 'TO' Expression [ 'STEP' ['+' | '-'] NUMBER ] Sequence 'END' 'FOR'.
```

Նշենք, որ `STEP`-ի համար թույլատրում ենք միայն դրական կամ բացասական հաստատուններ։

Ենթածրագրի կանչի `CALL` հրամանը կարղ է մի քիչ հնաոճ ու արհեստական թվալ,
բայց այն ներմուծել ենք նաև հետագա պարզեցման նպատակով.

```ebnf
Call = 'CALL' IDENT [ ExpressionList ].
```
